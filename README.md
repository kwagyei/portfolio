# portfolio

Personal portfolio site — React, Material-UI, deployed on Netlify.

## Pages

- **Home** — intro and contact links
- **Projects** — project grid; each item opens its own detail view
- **Experience** — vertical timeline of roles and study

## Running it

```bash
npm install
npm start
```

Opens on http://localhost:3000.

```bash
npm run build
```

Builds to `build/` for deployment. `netlify.toml` holds the Netlify redirect rules for client-side routing.

## Built with

React (Create React App) · react-router-dom · Material-UI · react-vertical-timeline-component
